# 07 — Bug Fix Log

## Issue Log & Remediation Records

| Bug ID | Component / File | Severity | Symptom / Error | Root Cause | Fix Applied | Status |
|---|---|---|---|---|---|---|
| **BUG-01** | `DocTypePageHead.jsx` | **CRITICAL** | `Objects are not valid as a React child (found: object with keys {label, onClick})` | Component rendered `{primaryAction}` directly inside `<Button>` without inspecting whether it was an action object or string. | Unified prop contract to extract `label`, `onClick`, and `variant` safely while maintaining backward compatibility with string labels. | **FIXED & VERIFIED** |
| **BUG-02** | `Button.jsx` | **HIGH** | Potential React crash if action object passed as children | Rendered `{children}` without checking if an object was supplied. | Added safe extraction of `children.label` and `children.onClick` into button handler. | **FIXED & VERIFIED** |
| **BUG-03** | `EmptyState.jsx` | **MEDIUM** | Potential crash or missing action if string or JSX element passed | Assumed `action` prop always was an object with `.label` and `.onClick`. | Added `renderAction()` supporting `isValidElement`, action objects, and string labels. | **FIXED & VERIFIED** |
| **BUG-04** | `StatusBadge.jsx` | **MEDIUM** | Potential crash if `status` passed as `{ label, status }` object | Rendered `<span>{label \|\| status}</span>` directly. | Added safe object unwrapping for `statusKey` and `resolvedLabel`. | **FIXED & VERIFIED** |
| **BUG-05** | `Input.jsx`, `Select.jsx`, `DatePicker.jsx`, `AsyncLinkField.jsx` | **MEDIUM** | Potential crash if validation error object passed to `error` prop | Rendered `{error}` directly as child. | Wrapped error display with `typeof error === 'object' && error !== null ? error.message : error`. | **FIXED & VERIFIED** |
| **BUG-06** | `PaginatedTable.jsx` | **LOW** | `[object Object]` displayed on unhandled relational object cells | Default cell fallback was `String(row[col.key])`. | Added smart object extraction checking `name`, `title`, `label`, or `code`. | **FIXED & VERIFIED** |
| **BUG-07** | `Alert.jsx` | **LOW** | Potential crash if Error instance passed to `message` prop | Directly rendered `{message \|\| children}`. | Added safe extraction for `message.message \|\| message.error`. | **FIXED & VERIFIED** |
| **BUG-08** | `HeroBanner.jsx` | **LOW** | Potential crash if `buttonText` passed as `{ label, onClick }` object | Directly rendered `<span>{buttonText}</span>`. | Added safe unwrapping for `resolvedButtonText` and `handleButtonClick`. | **FIXED & VERIFIED** |
| **BUG-09** | `PrivateLayout.jsx` | **HIGH** | Page failure in one route causes entire sidebar and navbar to unmount | No route-level error boundary wrapped `<Outlet />`. | Wrapped `<Outlet />` with an `ErrorBoundary` keyed by `location.pathname`. | **FIXED & VERIFIED** |
| **BUG-10** | `EventList.jsx` | **HIGH** | Syntax error: duplicate leftover tab switcher button block | Incomplete replacement during previous edit. | Cleaned up duplicate lines 283–304. | **FIXED & VERIFIED** |
| **BUG-11** | `statsService.js` | **HIGH** | `totalStudents` displays `0` on dashboards despite existing student records | `studentService.getStudents` pagination normalizes total elements to `totalItems`, but `statsService.js` was accessing `data.totalElements`. | Added fallback checking `data?.totalItems ?? data?.totalElements ?? data?.items?.length ?? 0` across all aggregate stats queries. | **FIXED & VERIFIED** |
| **BUG-12** | `AuthProvider.jsx` | **MEDIUM** | Offline mock credentials fallback could silently activate in production on 404/503 network errors | Offline mock authentication was not strictly restricted to local development environments. | Gated fallback strictly behind `import.meta.env?.DEV`; production always propagates backend auth errors. | **FIXED & VERIFIED** |
